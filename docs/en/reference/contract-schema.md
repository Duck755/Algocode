# Contract Schema

The Project Contract is normally located at:

```text
.algocode/contract.json
```

It is generated by Contract Discovery and records observable behavior that must remain stable outside the algorithm itself. Fields use camelCase.

## Top-Level Fields

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `schemaVersion` | int | `1` | Schema version. |
| `purpose` | string | required | Project purpose. |
| `entrypoints` | list[string] | `[]` | Program entry points. |
| `publicApi` | list[object] | `[]` | Public API list. |
| `configuration` | list[object] | `[]` | Configuration field semantics. |
| `stateTransitions` | list[string] | `[]` | State transition constraints. |
| `errorContracts` | list[string] | `[]` | Error behavior contracts. |
| `observableOutputs` | object | see below | Deterministic and volatile outputs. |
| `invariants` | list[string] | `[]` | Structural invariants. |
| `performanceGoal` | string | `""` | Performance goal. |
| `mustNotChange` | list[string] | `[]` | Paths, symbols, or semantics that must not change. |
| `protectedFiles` | list[string] | `[]` | Contract-protected files. |
| `unknowns` | list[string] | `[]` | Unresolved contract items. |
| `testObligations` | list[object] | `[]` | Executable test obligations. |
| `confidence` | float | `0.5` | Contract confidence from 0 to 1. |
| `contractTestSource` | string | `""` | Contract Test source. |
| `contractSource` | string | `"model"` | Contract source. |

## `publicApi`

```json
{
  "publicApi": [
    {
      "symbol": "solve",
      "signature": "def solve(values: list[int]) -> int",
      "behavior": "returns the sum of all values"
    }
  ]
}
```

| Field | Type | Description |
| --- | --- | --- |
| `symbol` | string | Symbol name. |
| `signature` | string | Signature description. |
| `behavior` | string | Observable behavior. |

## `configuration`

```json
{
  "configuration": [
    {
      "field": "workers",
      "default": "4",
      "variants": ["1", "4", "8"],
      "mustHonor": true
    }
  ]
}
```

| Field | Type | Description |
| --- | --- | --- |
| `field` | string | Configuration field name. |
| `default` | string | Default value or semantic description. |
| `variants` | list[string] | Configuration variants whose behavior must remain stable. |
| `mustHonor` | bool | Whether this setting must be honored. |

## `observableOutputs`

| Field | Type | Description |
| --- | --- | --- |
| `deterministic` | list[string] | Outputs that must remain deterministic. |
| `volatile` | list[string] | Outputs allowed to vary. |

```json
{
  "observableOutputs": {
    "deterministic": ["stdout"],
    "volatile": ["timing", "process_id"]
  }
}
```

## `testObligations`

```json
{
  "testObligations": [
    {
      "target": "sort(items)",
      "assertion": "returns a non-descending sequence with the same elements",
      "kind": "behavior"
    }
  ]
}
```

| Field | Type | Description |
| --- | --- | --- |
| `target` | string | Verification target, required. |
| `assertion` | string | Assertion description, required. |
| `kind` | string | Obligation type, default `behavior`. |

## Example Fragment

```json
{
  "schemaVersion": 1,
  "purpose": "solve a deterministic graph shortest-path problem",
  "entrypoints": ["main.py"],
  "publicApi": [],
  "stateTransitions": [],
  "errorContracts": ["invalid input must return a non-zero exit code"],
  "observableOutputs": {
    "deterministic": ["stdout"],
    "volatile": []
  },
  "invariants": ["output length must be non-negative"],
  "confidence": 0.9,
  "contractSource": "model"
}
```
