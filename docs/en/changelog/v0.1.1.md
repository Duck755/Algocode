# v0.1.1

## Added

- Added the VS Code extension entry point with right-click optimization for `.py`, `.cpp`, `.cc`, and `.cxx` files.
- Added `algocode vscode install` for installing the bundled extension.
- `algocode status` now shows phase progress: current phase, turn, tool count, active tool, last tool, and elapsed time.
- `algocode report` now also writes `report.md` at the project root while preserving internal JSON and Markdown artifacts.
- Analyze entrypoint commands accept both strings and arrays.
- Reworked the `algocode init` experience with a live phase rail in TTY mode, an evidence-chain summary, and a next-step menu. Non-TTY, `--json`, and `--quiet` disable progress; `--progress` and `--no-progress` force override.
- Added `--yes` to skip the pre-run confirmation.
- Reworked `algocode optimize` and `algocode retry` progress output with permanent success or failure lines and Chinese phase/tool labels.
- Added an optimize summary, evidence chain, and next-step menu.
- Added `--progress/--no-progress` to both optimize and retry.
- Progress is written only to `stderr` and reuses the same facts as `algocode status`.

## Fixed

- Fixed incorrect contract-file filtering when the candidate worktree path itself contained `.algocode`.
- Adjusted Windows sandbox backend selection so WSL2 can be preferred over Native.
- Fixed `.algocode/current-task.json` inheriting task state from parent directories. Each project now writes its own complete task state.

## Documentation

- Added Getting Started, Command Guide, User Guide, Core Concepts, Reference, and Development sections.
- Added separate quick and complete workflow documentation.
