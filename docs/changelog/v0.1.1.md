# v0.1.1

## 新增

- 新增 VS Code 扩展入口，支持在 `.py`、`.cpp`、`.cc`、`.cxx` 文件上右键优化。
- 新增 `algocode vscode install`，可安装内置 VS Code 扩展。
- `algocode status` 增加阶段进度展示：当前阶段、轮次、工具数量、active tool、last tool 和阶段耗时。
- `algocode report` 同时生成项目根目录 `report.md`，并保持内部 JSON/Markdown 产物不变。
- Analysis 入口命令支持字符串或数组形式，便于不同项目配置。

## 修复

- 修复 Contract 文件过滤时，候选 Worktree 路径本身包含 `.algocode` 导致的误过滤问题。
- 调整 Windows 下 Sandbox 后端选择，允许 WSL2 优先于 Native。

## 文档

- 文档站点新增 `快速上手`、`命令手册`、`用户指南`、`核心概念`、`参考文档` 和 `开发维护`。
- 新增简略工作流与完整工作流拆分说明。
